# 多视频项目与字幕队列

顶部“批量生成字幕”可选择多个视频或音频；主页支持同时拖入多个文件，批量面板也可追加拖入文件。每个文件建立独立项目，项目保存到源文件目录。文件名冲突使用 `视频名 (1).zimu` 等递增后缀，不覆盖已有文件。

统一参数包括源语言、识别模型、是否翻译和翻译服务；每行可选择“单项覆盖”。文件、重复项、模型、sidecar 和目录写入权限在提交前检查，错误显示在对应行。提交后参数固定。默认并发为 1，可设为 2；本地翻译共用一个串行调用的模型进程，识别失败时可自动回退到 CPU。

任务中心提供追加批次、暂停/继续、取消单项或全部、重试以及清除已结束记录。暂停只停止启动新任务；降低并发也不会结束正在运行的任务。单视频生成与重译同样进入全局队列。

项目下拉框可随时切换。等待、运行及已中断的项目暂时只读；已完成项目可以编辑，切换时保留修改、撤销记录及播放位置。后台完成不会改变当前项目。

识别完成后先保存原文，翻译完成后更新项目；翻译失败保留已生成字幕。项目及队列使用临时文件加原子替换。队列在应用私有目录中保存必要的项目引用、参数和结果，API 密钥继续使用 safeStorage。错误消息不会直接展示 sidecar 或 API 返回的敏感内容。

重启后队列保持暂停，上次运行中的任务标记为“已中断”。点击继续后重新检查资源，并从头执行中断任务。恢复时优先读取项目文件，因此已保存的人工校对不会被队列中的旧副本覆盖。首版不扫描文件夹、不批量重生成已有项目，也不自动导出或压制视频。

## 验证

```powershell
npm run typecheck
npm test
npm run build
npm run test:queue-electron
```

Electron 验收使用隔离 profile 和生成的 WAV 测试文件，检查真实 renderer/preload/main、恢复提示、项目切换、只读、编辑保存、多选与行级错误、队列控制和再次启动。截图放在 `artifacts/queue-smoke-*`，不会提交到 Git。调度、GPU/CPU 回退和共享本地模型的测试使用受控 sidecar/翻译替身；实际模型的识别质量和双视频 GPU 性能需在具备模型的机器上验证。
